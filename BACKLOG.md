# VP6 backlog

- **[Self-hosting]** Process for the IDE's helper programs: an `Environment` collection (the system's variables to start with; add, change or remove before `Start`), standing in for `QProcessEnvironment` when the IDE runs a program, `claude -p`, `codex app-server` and `vp6-make`; an `Arguments` list beside `CommandLine`, so paths with spaces and quotes need no quoting; and a function that opens a URL, document or folder with what the system uses for it (VB's ShellExecute; the browser for Codex's login, Finder/Explorer for a built wheel), standing in for `QDesktopServices.openUrl`.
- **[Self-hosting]** CommonDialog's `ShowFolder`: choose a folder (VB's BrowseForFolder), for New Project's Location (`QFileDialog.getExistingDirectory` in `ide/dialogs.py`).
- **[Self-hosting]** A Winsock control: TCP client and server (`Listen`, `ConnectionRequest`/`Accept`, `Connect`, `SendData`, `DataArrival`/`GetData`, `Close`, `Error`, `State`), for the debugger's `DebugSession`, which listens with `QTcpServer` for the program's debug agent.
- **[Self-hosting]** A FileWatcher control (`Add`/`Remove` files and folders; `FileChanged`/`FolderChanged` events; files that editors replace rather than rewrite keep being watched), standing in for `QFileSystemWatcher` in `check_disk_changes` and the Project view; App events for the application becoming active or inactive (`applicationStateChanged`, used to check files changed on disk); and a safe way to run code on the GUI thread from worker threads (the Output window's reader threads in `outputcapture.py` use a Qt signal).
- **[Self-hosting]** Appearance at run time: an app-wide `ColorScheme` (Light, Dark or System, like the project's setting but changeable while running, every form getting `ColorSchemeChanged`) and an app-wide style (native or Fusion), for the IDE's theme menu and Options (`ide/theme.py`'s ThemeManager sets the application's palette and style).
- **[Self-hosting]** Docking like the IDE's: DockPanels tabbed together (`TabWith`; the group's active tab; a panel hidden or shown inside its group, as the Terminal joins Immediate and Output), several panels side by side in one area with their sizes, DockPanels on an MDIForm around its client area, and the whole layout saved and restored as a string for SaveSetting (`SaveLayout`/`LoadLayout`), standing in for `tabifyDockWidget` and `saveState`/`restoreState`.
- **[Self-hosting]** MDIForm's tabbed view: `ViewMode` (windows or tabs; closable, movable tabs), for View > Tabbed Documents (`QMdiArea.TabbedView`), with several instances of one form class as children (a designer or code window per file).
- **[Self-hosting]** Menu items with pictures (`Menu.Picture`, redrawn when the color scheme changes) and groups of menu items where one is checked (`QActionGroup`, the theme menu); toolbar buttons and menu items sharing an icon.
- **[Self-hosting]** Graphics for the IDE's own pictures: linear gradients, colors with alpha, rounded rectangles and paths with Bézier curves in the graphics methods of forms, PictureBoxes and Pictures, so `ide/icons.py` (the toolbar, menu and Toolbox icons, drawn with `QPainterPath`, `QLinearGradient`) and `ide/chrome.py` (the designer's macOS, Windows and Fusion window frames) can be VP6 code; or ship those icons as SVG/PNG files with light and dark versions, loaded with LoadPicture.
- **[Self-hosting]** CodeBox for the code window: a completion list at the caret (filtered while typing; an event for the chosen item; the `QCompleter` in `codeeditor.py`); Find and Replace with regular expressions, whole words and match case, returning positions for Find All; highlights apart from the coloring (the current statement in break mode, found text, errors); replacing a span as one undo step that keeps the cursor and scrolling (`Document.reload`); comment/uncomment selected lines.
- **[Self-hosting]** FlexGrid for the Properties window: outline rows (collapsible category headings for the Categorized view), the editors the Properties window uses (enumerations, colors with palette and system tabs, fonts, pictures, numbers, "..." for lists such as Tabs and Panels), and a description pane under it (`ide/properties.py` is a `QTreeWidget` with its own editors).
- **[Self-hosting]** A public, documented API for control metadata: the control types (Toolbox order and categories, default sizes, icons as Pictures), their properties (kind, default, choices, category, description: today's private `_specs` and `PropSpec`), and their events with their arguments, for the Toolbox, the Properties window, the Object Browser and the code window's object and event lists.
- **[Self-hosting]** A form designer control: shows a form from its definition (`formfile`) with its controls in design mode (no events run), the platform's window frame and menu bar (`chrome.py`), selection and grab handles, rubber-band selection, the grid and snapping, moving controls between containers and pages, drops from the Toolbox, arrow-key nudging, locked controls, and events for every change (selection changed, control added, moved, resized, deleted; double-click to go to code), so the Properties window and undo can be VP6 code; `ide/designer.py` is the reference.
- **[Self-hosting]** A VP6 project that is part of a Python package: its forms and modules imported by package name instead of from its folder on `sys.path` (the runner's `import_folders`; module names such as `designer` or `options` would shadow others, as `vp6help/` once did), started from a console entry point (`vp6-ide`) through Sub Main, its resources (templates, images, help) found in the package; and `vp6-make` building such a project into a package of a larger wheel.
