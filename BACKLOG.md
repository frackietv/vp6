- **[IDE - Help]** IDE needs a help system (vp6help) that works like the old .chm help.  The system should be built into a separate wheel, thatn VP6 depends on.  The system will consist of a help builder and help UI.  The help UI will have a navigattion paenl on the left and document pane on the right.  The navigation panel has three tabs: table of contents - a structured headings based on the content provided, index - an alphabetized list of keywords/tags/tec, with a filter input that reduces the content of the index based on filter (filter can be a string or regex, case sensitive or not), and a search tab that searches all of the documentation (again text or regex, case sensitive or not).  The help maker will accept input of markdown and HTML documents, linked images, etc and build a single file containing the documentation, readable by the help ui.  A flag should also allow help maker to dynamically generate documentation based on python packages specified, optionally indexing all of the referenced pacakges as well (kind of like javadoc).  Each page in the documentation must be accessible by passing parameters to the help system, including search parameters, etc.  Finally, generate all documentation for vp6, including api and development guides, and should support table of contents, index, and search for the help system, and connect the help system to VP6 to allow accessing help about keywords, apis, etc from VP6.
